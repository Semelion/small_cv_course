# Проверки — 6 ноября 2026

Основное окружение пользователя: `/opt/anaconda3/envs/opencv/bin/python`, Python 3.14.4, OpenCV 5.0.0, NumPy 2.5.3, pyserial 3.5. Существующие зависимости не изменялись. Агенты дополнительно проверили обработку изображений и ArUco на OpenCV 4.12.0.

Проверено:

- Синтаксис всех семи Python-программ.
- Запуск трёх программ обработки изображений с `--no-gui`, в том числе из другой рабочей папки.
- Размер обрезки 160×200; совпадение окраски циклом и NumPy, без переполнения `uint8`.
- Два крупных зелёных объекта после фильтра площади; сохранение изображений и масок.
- Генерация ArUco DICT_4X4_50 и распознавание ID 7 на файле.
- pySerial loopback: окончание команды `\n`, ожидаемый `OK`, ошибка `ERR`, таймаут. Это проверка протокольных функций Python, а не настоящей платы.
- Список последовательных портов: подключённой учебной платы не обнаружено.
- Наличие локальных картинок и ссылок в HTML. Браузерный предпросмотр локального HTML недоступен из-за ограничения инструмента; иллюстрации обработки изображений просмотрены отдельно.

Не проверено на оборудовании: поток камеры, оконный GUI OpenCV, компиляция/загрузка Arduino-скетча и переключение физических LED. `arduino-cli` не установлен. Перед занятием преподавателю нужно выполнить аппаратную проверку по главам 2–3.

Схема для обычного Raspberry Pi Pico с тремя отдельными внешними LED на GP2/GP3/GP4. Для другой RP2040-платы сверьте выводы; встроенный RGB может быть подключён иначе.
