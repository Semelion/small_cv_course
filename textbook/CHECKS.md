# Проверки упрощённых примеров

Все семь учебных Python-программ написаны последовательно, без своих функций, классов, argparse, pathlib и main guard. Все пути — строки относительно папки CV_course. В Arduino остались только обязательные setup и loop.

Проверки выполняются в окружении курса с OpenCV. Проверяется синтаксис всех примеров, обработка учебной сцены, генерация и распознавание ArUco ID 7. Для автоматического прогона окна отключаются только проверочным инструментом: учебный код остаётся обычным кодом с imshow и waitKey. Циклы камеры проверяются на подставленном кадре, Serial — с имитацией ответов платы.

Это не аппаратная проверка: перед занятием нужно проверить настоящую камеру, скомпилировать и загрузить Arduino-скетч, подключить LED и проверить команды r/g/b/off. Схема рассчитана на обычный Raspberry Pi Pico с отдельными внешними светодиодами на GP2/GP3/GP4.

Простые примеры рассчитаны на штатный выход: окно изображения ждёт клавишу, камера закрывается по q или Esc, Serial — по q. При принудительной остановке или отключении USB выключение LED не гарантируется. Если после открытия Serial первая команда осталась без ответа, дождитесь готовности платы и повторите её.

## Сборка сайта для преподавателя

```bash
python -m pip install -r requirements-site.txt
python textbook/tools/build_book.py
python textbook/tools/check_site.py
```

Команды выполняются из CV_course. Служебные инструменты в tools не являются учебными примерами, и ученикам не требуется их разбирать.
